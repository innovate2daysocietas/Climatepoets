# Climate Poet

Climate Poet is a website that turns real NASA climate data into sound and poetry.

## What it does

You pick a place and a year. The site loads daily temperature and rainfall from NASA POWER and adds it up by month.

Then you can do two things with that data.

You can hear it. The Earth Jukebox plays the twelve monthly values as notes. Higher numbers mean higher notes. January plays first, then February, and so on.

You can also write about it. The Poetry Studio lets you write a poem, save drafts, record yourself reading it, or have the browser read it out loud. There is a button that asks an AI to write a poem using the data you loaded.

The community page shows poems that people submitted and that got approved.

## About the data

NASA POWER gives historical climate data. It is not a live forecast. Monthly temperature is the average of the daily values. Monthly rainfall is the total of the daily values.

The sound is calculated from the numbers. It is not a recording.
